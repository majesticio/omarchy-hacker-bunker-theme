Fastfetch configuration, and integration hook were created for this project.
They are covered by the MIT license in `LICENSE`.

## Original wallpaper artwork

`backgrounds/1-hacker-bunker.png` was created by the theme author and supplied
from the local machine at:

```text
~/Pictures/Wallpapers/hacker-bunker.png
```

The theme author retains the artwork copyright. It is published for download
and use as part of Hacker Bunker, but no separate reuse license is granted. It
is intentionally excluded from the MIT software license in `LICENSE`.

## Companion wallpapers

`backgrounds/2-abyss-relay.png` and `backgrounds/3-numbers-station.png` were
generated from scratch with OpenAI's built-in ImageGen for this theme. They did
not use the original wallpaper as an edit target or reference image.

`preview.png` is a screenshot of the theme in use and contains the original
wallpaper artwork.
